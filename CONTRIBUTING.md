# Contributing

We welcome issues, pull requests, and questions on any of our public repos. A few notes:

- **Open an issue first** for anything bigger than a typo fix. Saves us both time if the change isn't a fit.
- **Match the existing style** in the file you're editing.
- **Test what you change.** If a repo has tests, run them. If it doesn't, describe how you verified your change in the PR.
- **PRs should be focused** — one thing per PR makes review easier.

These projects exist because we built them for client work and decided the rest of the movement could use them too. We're a small team, so review may take a few days. Thanks for your patience.

Need paid support, custom development, or help running these tools at your org? See [SUPPORT.md](SUPPORT.md).
