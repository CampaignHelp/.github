# Security policy

## Reporting a vulnerability

If you've found a security issue in any CampaignHelp project, please email **jordan@campaign.help** rather than opening a public issue.

We'll acknowledge within two business days and work with you on a fix and disclosure timeline. We don't run a paid bug bounty, but we're grateful for responsible disclosures and will credit you in the release notes if you'd like.

For non-security bug reports, use the issue tracker on the relevant repo.
